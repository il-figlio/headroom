Headroom 0.9.0 is the first public release.

- Private builds up to 0.8.0 can't update themselves to this release: quit Headroom and install this DMG over it. On first launch Headroom moves your history to `~/Library/Application Support/org.headroom.app` (away from a folder another app called Headroom also uses), and your settings carry over.
- Download a notarized DMG. Later updates install in place from a public, signed feed and don't need a GitHub login.
- A short welcome on first launch, a Settings window (⌘,), and an About panel.
- Limits is opt-in on new installs. While it's off, Headroom reads no sign-ins and sends no usage requests. It supports Codex and Claude only, through the providers' unofficial usage endpoints.
- Claude limits can use Claude Code's Keychain sign-in when macOS grants Headroom access without a prompt. You can turn Keychain use off in Settings → Limits. Model-specific weekly windows (such as Sonnet or Opus) appear when Anthropic reports them.
- Named Claude accounts (such as Personal and Work) each get their own row through the Ante CLI, replacing the Claude Code row.
- Limits is easier to read: each account leads with its most constrained window, values say "% used", and readings that couldn't refresh are dimmed and labeled with when they were fetched.
- Hover any row, meter, or tile for details, in the notch panel and the menu bar.
- Agents is off by default and now leads with what's running and how much memory it uses.
- More accurate agent token counts, and lighter background work: readings appear first, and history and agent scans are several times cheaper.

Universal app for Apple Silicon and Intel, macOS 13 or later. Developer ID signed and notarized.
